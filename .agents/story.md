# short description

a windows app that generates script (.exe is preferred)

the script creates new folder based on user input

# detail

## problem definition

i have two windows machine for gaming (pc and handheld pc - rog ally)

sometimes i want to play a game that has no cloud sync support in both device - expecting to sync savegames between both device

the sync is solved via SyncThing app

but folder creation is a pain in the ass

## what this app solves

helps user with handheld pc - rog ally in this case, creates new folder for save files, that is similar with the one on pc. simple, yet helpful

## how does this app solves the problem

1. user can input a path manually into a text form
a. OR user can pick folder manually
2. user clicks "process" - the app starts creating script
3. the app creates a script on user desktop by default - user can choose where the script will be generated
